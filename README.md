# Influencer Landing Page 🚀

**Influencer Landing Page** is a modern landing page project built with **Next.js**. All components are developed using **React**, styled with **Tailwind CSS**, and enhanced with smooth animations using **Framer Motion**.  

## Features
- Fully component-based architecture using React.  
- Stylish and responsive layouts with Tailwind CSS.  
- Interactive animations and transitions powered by Framer Motion.  
- Optimized for modern web performance and user experience.  

## Status
⚠️ This project is **currently in development**.  
- Buttons are not fully functional yet.  
- Responsive design adjustments are still ongoing.  
- Some components and sections are incomplete.  

Even though the project is a work in progress, the code structure and design showcase the core concept and architecture.

## Tech Stack
- **Next.js**  
- **React**  
- **Tailwind CSS**  
- **Framer Motion**
